### 최종 export·네이티브 실물의 별도 확인과 인계

통합 담당은 **원격 기준 통합 작업본**에서 다음 명령의 exit `0`을 확인했다. `EXPO_NO_DOTENV=1`, `EXPO_NO_TELEMETRY=1`과 합성 환경값을 사용했으며 원격 배포가 아니다.

```text
node tools/앱시작.js export --platform all --max-workers 1 --source-maps --output-dir dist/action-runtime-integration-20260913
```

이 문서 담당은 생성된 번들 바이트·SHA-256과 source map의 `sources`를 읽기 전용으로 대조했다.

별도 [네이티브 v2 기록](액션런타임_네이티브검증_20260913.md)의 원문에서는 독립 x86_64 시험 APK `runtime-harness-v2-x86_64.apk`의 SHA-256 `4029d657def174814137e5e741c45a6c4f8ddfa522e6ff6b16e3dcbcdbb98563`와, 위 v2 운동장·시험 화면 소스 지문 일치를 확인했다. 담당의 실제 가상기기 조작에서 세로 입력은 화면 스크롤 없이 수락 1·충돌 1로 정산됐고, 운동장 바깥의 양방향 스크롤·자동 입력·단일 발사·초기화·닫기/재열기도 관측했다. 마지막 앱 오류·Skia 폐기 경고 0건, 시험 가상기기와 관련 빌드 프로세스 정상 종료가 기록됐다.

이는 **독립 시험대의 실제 입력 검수**와 **최신 원격 통합본의 production 구성 검증**이라는 서로 다른 두 증거다. 독립 시험 APK를 원격 통합본 전체 App의 로그인·인증·학생 경로를 검증한 APK로 바꾸어 부르지 않는다. 웹 실화면은 환경 정책으로 미확인이고, 물리 휴대전화의 지속 FPS·발열·배터리, iOS 네이티브 실행, 실제 OS 백그라운드 복귀·비행 중간 정지 등 네이티브 문서의 미확인 범위를 유지한다.
