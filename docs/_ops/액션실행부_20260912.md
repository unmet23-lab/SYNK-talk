# 액션 공통 실행부 · 개발용 시뮬레이션 시험

2026-09-12. 현재 범위는 앞으로의 액션 게임에 쓸 실행부·애니메이션 시험이다. 문장 선택과 활쏘기를 결합한 학생용 게임은 사용자가 거절했으며 제품 승인으로 해석하지 않는다. 아래 활·화살·표적은 개발용 운동 시험 소재이고, 물리 결과는 학습 정오가 아니다.

- 원천: `lib/액션실행부.js` (CJS). 독립 순수 함수마다 `worklet` 지시문을 둔다.
- 좌표: 너비 360, 높이 420. UI가 화면 좌표를 변환한다. 활 위치는 (180, 376).
- 생성: `createWorld(seed, {reducedMotion:false})`; 매 프레임 `advanceWorld(state, deltaMs)` 결과로 상태를 교체한다. `reducedMotion:true`는 표적을 정지하고 입자를 생략한다.
- 동작 줄이기 변경: `setReducedMotion(state,bool)`은 진행 중인 화살·조준·시간·결과를 보존한다. 표적 위상을 조절해 설정 순간 위치가 뛰지 않으며, 켜면 기존 입자도 제거한다.
- 입력: `beginAim(state,x,y)` → `moveAim(state,x,y)` → `releaseArrow(state)`. 손가락이 가리킨 방향으로 발사하며 거리가 당김을 정한다. 취소는 `cancelAim`.
- 접근성 보조: `assistShot(state)`는 24스텝 뒤 표적 위치와 중력을 역산해 실제 화살을 발사한다. 키보드·스크린리더 버튼에 연결할 수 있다. 즉시 성공을 쓰지 않고 같은 충돌 검사를 지나며, 한국어 학습 정오를 만들지 않는다.
- 일시중지: `setPaused(state,true)`는 누적 시간과 조준을 비운다. 재개는 false. 화면 복귀 시 첫 프레임 delta는 UI에서도 버리기를 권장한다.
- 초기화: `resetWorld(state,seed?)`; 생략하면 최초 seed로 재현한다.
- 결과: `lastResult={kind:'hit'|'miss',shotId,x,y}`. 식별자는 운동 샷 순서일 뿐 학습 제출 키가 아니다. `hits`, `misses`, `shots`는 화면 연출용이다.
- 성능 경계: 120Hz 고정 시간 스텝, 프레임당 최대 8스텝, 긴 지연은 약 66.7ms로 제한. 화살 최대 4, 파티클 최대 48. 표적과 화살의 상대 이동 선분으로 연속 충돌 검사한다.
- 확인: `node --test tests/액션실행부.test.js` **19/19 통과**. 30/60/120Hz 입력 간 결과 동등, 시간 입력 경계, pause/reset, 빠른 화살 관통 방지, 결정성, 개체 상한, 보조 발사, 동작 줄이기를 검증했다. 이 추가 시험에서 실행부 원본은 수정하지 않았다.

## 반복 시험 기록

- 가상 시간 10분: 60Hz 입력 36,000회 → 120Hz 고정 스텝 72,000회, 상태의 시간 600초. 매초 1회씩 총 600회 발사 후 전부 정산되고 마지막 화살·입자는 0개였다.
- 연속 발사: 실행부가 실제 수락한 발사 1,000회까지 상한 초과 입력을 반복했다. 같은 seed·입력열로 2번 실행해 최종 상태와 소요 프레임 호출 수가 동일함을 확인했다. 각 실행 후 가상 3초(180회 입력)를 더 진행해 미정산 화살·입자 0개를 확인했다.
- 폭주 시간: `Number.MAX_VALUE`, 60,000ms, 10억ms, NaN, ±Infinity, 음수, 0, 작은 소수 스텝, 정상 간격을 섞어 10,000회 입력했다. 매 호출 0~8스텝 제한과 무효 시간 입력의 상태 불변을 확인했다.
- 설정 회귀: 비행 중 동작 줄이기 변경 → 일시중지 → 재개 → 초기화를 100회 반복했다. 화살 보존, 조준 취소, 표적 위치 연속성, 정산 보존, 초기 seed와 동작 줄이기 설정 재현을 확인했다.
- 공통 불변식: 매 검사에서 화살 ≤4, 입자 ≤48, 수치 상태 유한, 누적시간 0 이상·1스텝 미만, 표적 이동 범위, 살아 있는 화살 식별자 중복 없음, `shots = hits + misses + arrows.length`를 확인했다.

이 수치는 **순수 JavaScript 상태 시뮬레이션 횟수**다. 실제 10분 기기 구동, 화면 FPS, GPU/메모리 사용량, Reanimated UI 스레드 안정성, 배포 또는 학생의 자연 사용을 검증한 결과가 아니다.

```js
// Reanimated UI worklet 안에서 호출하는 예시. shared.value의 내용은 이 반환값으로 교체한다.
shared.value = advanceWorld(shared.value, frame.timeSincePreviousFrame || 0);
// 제스처 좌표: beginAim(shared.value, localX * 360 / width, localY * 420 / height)
```
