## 이번에 일괄 변경하지 않은 것

React Native 0.87.1, React 19.3.0, Sentry 8.26.0은 npm 공식 registry에서 확인했다. 그러나 Expo SDK 57 권장 묶음은 React Native 0.86.3·React 19.2.3·Sentry 7.11이다. 이들을 따로 최신 숫자로 올리면 현재 지원 묶음을 벗어난다. Expo의 차기 묶음과 실제 기기 호환성이 확인될 때 통합한다. 신규 구독·자동충전·유료 모델 호출은 이번 조사·설치에서 발생시키지 않았다.
