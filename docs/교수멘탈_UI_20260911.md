# 교수멘탈 화면 갱신 · 2026-09-11

사용자가 `http://127.0.0.1:18769/__fixture/confirmation`의 낡은 BGM·자산·UI를 지적하고 현행 4K 자산과 새 Suno 음악을 요청했다. 이 결과는 해당 G1 화면과 로컬 미리보기다. 학생 G1 진입의 `검수확정=false`는 유지하며 운영 앱 배포나 실학생 이용으로 세지 않는다.

## 반영

- 현행 appsscript `DESIGN.md`·디자인 토큰·내부 로고 정본과 synk-design·synk-brand·make-interfaces-feel-better를 적용했다. Ink Deep 바탕, Ink 면, Paper 글자와 현행 Stitch `#FBCAAB`를 쓴다.
- 상황·전략 선택, 메일 작성, 전송 대기와 확인 응답의 세 단계를 다시 배치했다. 넓은 화면은 상황 설명과 작업 영역을 나란히, 휴대폰은 한 열로 놓는다. 수신자·입력·주행동·선택적 확인 응답의 위계를 분리하고 선 아이콘을 사용했다.
- SUIT·Inter Tight·DM Mono의 실제 폰트 8파일을 별도 미리보기 진입에서도 로드한다. 한국어 설명은 웹에서 어절 단위로 줄바꿈한다. `맞아요`와 `아니에요`는 같은 크기·강조를 유지한다.
- 교수 4상태는 기존 336px 그림 대신 현재 4K 생성 원본에서 1024px WebP를 다시 만들었다. 원본은 투명 여백을 잘라 실제 치수가 2261×2925~2557×3265이며, 4096 정사각 그림이라고 부르지 않는다. 내부 로고도 현행 생성기의 4096px 원본에서 앱용 1024px 파일로 만들었다. 변환기와 출처 SHA-256을 함께 갱신했다.
- 가이드 3종의 현행 본체도 별도 브랜드 자산 모듈에 반입했다. 이 G1 화면은 교수 상대역을 쓰며 선택되지 않은 가이드를 임의로 노출하지 않는다. 다른 게임의 NPC와 전체 가이드 표정 24종을 이번 작업에서 모두 교체한 것은 아니다.
- 이 화면의 구형 BGM 자동재생을 제거했다. 진입·퇴장 때 남은 BGM을 정지한다. 발송 효과음과 다른 게임의 음악 통로는 보존했다.
- 읽음이나 사람 검수 완료를 확인한 것처럼 말하던 문구를 답장 대기 안내로 맞췄다. 미리보기의 새 과제 번호와 재열기 번호를 분리해 같은 편지·전송 상태 복원을 확인할 수 있게 했다.

## 확인 증거

실제 Expo 웹 빌드 및 별도 확인 화면 번들 생성 완료. 브라우저에서 1280px·390px·360px 너비를 확인했다. 실제 표시된 내부 로고는 1024×383, 교수는 1024×1024이며 이미지 로딩 완료, 질문의 계산된 폰트는 `SUIT-Medium`, 줄바꿈은 `keep-all`이다. 브라우저 오류는 없었고 React Native Web의 기존 native animation → JavaScript 대체 경고 1건은 남는다.

실제 컴포넌트로 전략 선택 → 빈 본문 전송 비활성 → 한글 본문 입력과 5칸 안내 → 전송 대기 → 수락 후 보냈어요 → 같은 화면 재열기와 본문 복원을 확인했다. 한글 문자열 보존을 확인한 것으로 물리 키보드 IME 전체 검증을 대신하지 않는다.

합성 확인 카드에서 `리듬:여유제출`에 `아니에요`를 누른 뒤 재진입하면 해당 키가 제외되고 `집중띠:주로오후` 후보로 바뀐다. 서버 관찰은 `estimate.received` 뒤 `progress:주로오후`, 응답 1건·부정 키 1개다. 이것은 합성 서버의 실제 화면 왕복이며 원격 DB나 학습 효과 증거는 아니다.
