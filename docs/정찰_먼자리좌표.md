## 온디바이스 STT — react-native-executorch

- **무엇**: Software Mansion 의 react-native-executorch 가 `useSpeechToText` 훅으로 Whisper·Moonshine 을 온디바이스로 돌린다(v0.3.0 신설 · 현행 0.4.x). Expo 공식 블로그가 폰 마이크→로컬 Whisper 받아쓰기를 시연했다.
- **우리 자리**: 발음 데이터 트랙 낱말 11개의 «기기 안» 발음 대조 — 서버 왕복 없이 발음을 재는 유일한 무거운 길 후보.
- **문지기**: 모델이 수십~수백MB · 몽골 저사양 기기 램(굽기 램 병목과 같은 축) · 실기기 실측 불가(에뮬 통로 막힘 08-25).
- **지금 앱 실물**: executorch 반입 0건 — `grep -ri executorch src lib package.json App.js` = 0 (실측 2026-08-31).
- **재개봉**: latest-ai-scouting-gate 정찰 때 이 절부터 다시 본다.
- **출처**: expo.dev/blog (폰 마이크→로컬 Whisper 시연) · docs.swmansion.com (react-native-executorch 0.4.x `useSpeechToText`)

## Skia Graphite — 채택하지 않는다

- **무엇**: Skia 의 Graphite 백엔드 — WebGPU·자동 스레딩·2D/3D 합성 통합. react-native-skia v2.10.1(07-29)·v2.12.0-next(08-06)에 이식이 진행 중이다.
- **판정**: 채택하지 **않는다**. 2026-04 기준 상류가 프로덕션 비권장 + Android API 26+ 요구 + 저사양 실측 불가(에뮬 통로 막힘)라, 성숙 전 도입은 위험만 산다. 캐릭터 3D 금지(유호 기각 08-26)와는 무관한 «렌더 백엔드» 층이다 — 3D 콘텐츠를 들이는 게 아니라 2D 를 그리는 밑단이 바뀌는 것.
- **익으면**: 몽글 메시 변형 프레임이 자산 변경 0으로 빨라지는 자리.
- **재개봉 조건 셋**: ① 상류의 프로덕션 권장 선언 ② react-native-skia 안정판 이식 완료 ③ Android API 26+ 하한이 우리 대상 기기와 맞는지 대조.
- **우리 현행**: @shopify/react-native-skia 2.6.2 (package.json 실측 2026-08-31 · S3-3 이 판을 올리면 그 판 기준으로 다시 본다).
- **출처**: shopify.engineering (Graphite 이식 글) · github.com/Shopify/react-native-skia releases

## Realtime Broadcast 바이너리 페이로드

- **무엇**: Supabase Realtime Broadcast 가 bytea 페이로드를 WebSocket·REST·DB 경유로 나른다(2026-07) — base64 의 33% 크기 세금이 사라진다.
- **함정(이 절의 심장)**: supabase-js **2.91.0+** 필요 — 구판 클라이언트는 바이너리 메시지를 **조용히 버린다**(오류 없음). 들이는 날, 클라이언트 판 하한을 계약으로 못 박을 것.
- **우리 현행**: 신앱은 fetch 전용, supabase-js 의존 0건(package.json 실측 2026-08-31 — supabase-js 언급은 Edge Fn 서버 쪽 주석뿐: `supabase/functions/auth/index.ts` 등) → 지금 들일 일 없음.
- **쓰는 날**: radio 스키마(자막카드·퀴즈라운드)의 봇→시청 화면 실시간 푸시 · 장차 c14 강사 실시간 관찰 층. 그날의 첫걸음은 «앱에 supabase-js 채택» 판정부터라 일의 크기는 중간.
