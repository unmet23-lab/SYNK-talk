## §0 범위·전제

- 범위: 4단계 로드맵의 **1단계(DB+파이프라인) + 3단계(대시보드)**. 2단계(마이크로 챌린지 UI)는 별도 발주.
- 대시보드 = **Expo 확정**(유호 08-06 "expo로 해줘"): SYNK-talk 앱 안의 검수자 역할 화면, PC에서는 Expo web 빌드로 사용. 한 코드베이스.
- 말하기 과제 = **20~30초**(유호 확정). 검수 = 저신뢰 구간 + 무작위 5% 감사 레인.
- **오디오 = PCM WAV 16kHz/16bit mono · 기기 음성처리(AGC·노이즈 억제) off** — `C0_API계약.md` `content_type: audio/wav`와 같은 값이어야 한다(회귀 `tests/C0계약.test.js`). 🔴압축·AGC는 떨림과 미세 발음을 지우고, **지워진 신호는 원본이 없어 영영 복원되지 않는다**(소급 불가 배선①).
- ⛔ **수집 개시 게이트**: 동의 6항목(음성·얼굴영상·교실녹음·국외이전·제3자 처리·철회 시 기학습 유지) 개정 **후**에만 실데이터 수집 시작 — 개정 전 수집분은 엔진에 못 쓴다(소급 불가). 🔴**문구는 ✅유호님이 직접 준비 완료**(2026-08-06)·🚫재질의 금지 — 「문구 초안 = 클로드 몫」이라던 이 줄의 옛 표기는 **틀렸다**(F126). 저장소 사본과 6항목의 대조표 = `docs/동의_문구_v1.md` §CHK-5.

### 기각·보류 (판정 유지 · 재론 불요)

- 🚫 **노이즈 다양화·하드모드 소음** — 소음은 사후 합성 가능. 수집 항목이 아니라 경험 백로그(2신 ⑨ 판정 유지).
- 🚫 **조음 위치 3D 시각화(혀·입술)** — 단안 카메라엔 기준자가 없어 절대값이 안 나온다. 원순 모음 3쌍·서버측으로 축소된 것이 정본(§7).
- ⏸ **음소 단위 Forced Alignment** — 지금 안 한다. **원본 WAV를 무손실로 보존하므로 언제든 소급 가능**하고, 지금 붙이면 파이프라인만 무거워진다.
- ⏸ 세션 리포트·TTS 3단계 속도·상대 랭킹·신조어 DB·비자 RAG 지식베이스·B2B 산업 데이터셋 — **전부 수집이 아니라 앱 기능/콘텐츠**다. 필요한 원천(어휘 등급·WPM·정적·오류 유형)은 이미 위 스키마에서 파생된다.
- ⏳ **상급생이 몽골어로 해설**(H-1) — 2신 도전안 「선배 학생 유료 마이크로워크」와 같은 항목, 유호 답 대기 중.
- ⏳ **문화적 거부감·정의적 여과막**(H-4) — 검수자가 판정할 수 없는 값(학생 자기보고여야 함). 앱 2단계에서 1문항으로.
