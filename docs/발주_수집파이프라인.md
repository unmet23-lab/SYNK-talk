## §0 범위·전제

- 범위: 4단계 로드맵의 **1단계(DB+파이프라인) + 3단계(대시보드)**. 2단계(마이크로 챌린지 UI)는 별도 발주.
- 대시보드 = **Expo 확정**(유호 08-06 "expo로 해줘"): SYNK-talk 앱 안의 검수자 역할 화면, PC에서는 Expo web 빌드로 사용. 한 코드베이스.
- 말하기 과제 = **20~30초**(유호 확정). 검수 = 저신뢰 구간 + 무작위 5% 감사 레인.
- **오디오 = PCM WAV 16kHz/16bit mono · 기기 음성처리(AGC·노이즈 억제) off** — `C0_API계약.md` `content_type: audio/wav`와 같은 값이어야 한다(회귀 `tests/C0계약.test.js`). 🔴압축·AGC는 떨림과 미세 발음을 지우고, **지워진 신호는 원본이 없어 영영 복원되지 않는다**(소급 불가 배선①).
- ⛔ **수집 개시 게이트**: 동의 6항목(음성·얼굴영상·교실녹음·국외이전·제3자 처리·철회 시 기학습 유지) 개정 **후**에만 실데이터 수집 시작 — 개정 전 수집분은 엔진에 못 쓴다(소급 불가). 문구 초안 = 클로드 몫(별도).
- Gemini = **유료 티어 필수**(무료 티어는 구글 학습에 사용 — 학생 데이터 금지). 모델 = 현행 flash(3.6 계열).

## §4 수용 기준 (전부 통과해야 완료)

1. 새 Supabase 프로젝트에 **`supabase/L0_스키마.sql`** 원샷 적용 — 오류 0 · 꼬리 확인 `판정` 칸 = 「✅ 전부 통과」.
   🔴 **기대 숫자를 여기 적지 않는다** — 그 값은 기준선 파일이 스스로 들고 있고(❌일 때 화면이 직접 알려준다),
   문서에 복사하면 다음 계약 개정 때 **정상 적용이 ❌로 보이는** 사고가 난다(기준선 발주서 §2-1 — 같은 형태 3회).
2. 학생 A 계정으로 학생 B 행 select → 0행(RLS 실측). **+ 학생 토큰으로 insert 시도 → 거부**(쓰기는 Edge Function만).
3. 실제 몽골 억양 20~30초 음성 1건: 제출→`ai_processed` 자동(수동 개입 0) · `submissions.stt_segments`·`corrections`(ai) `model`·`prompt_ver` 채워짐.
4. 대시보드 왕복 1건: 수정 승인 → **teacher `corrections` 행**에 `reviewed_correction_id`(AI 행) + `verdict='고칠 곳이 있다'` + `review_listened_ms>0`, **`submissions.transcript_verified` 채워지고 `transcript`는 그대로**.
5. 청취 0초 상태에서 Enter → 승인 안 됨(게이트 실측).
6. 폐기 1건: `pipeline_jobs.status='discarded'` 인데 Storage 파일 존치.
   **철회 1건**(같은 축의 반대 실측): `data_use.revoked` 이벤트 + `consents.revoked_at` + **Storage 파일 실제 부재** + `submissions.audio_deleted_at` 채워짐 + 행은 남아 있음.
7. n8n 죽인 상태로 1건 제출 → 재기동 후 자동 처리(폴링 자가치유 실측). **+ 워커 2개 동시 기동에 같은 행이 두 번 처리되지 않음**(`skip locked` 실측) · **lease 만료분이 자동 회수됨**.
8. 실기기 2대(iOS/Android) 녹음 파일이 WAV/PCM 16kHz mono인지 파일 헤더로 실측(배선① — 압축·AGC가 신호를 지우면 소급 불가).
9. pg_cron 다음날 `engine.daily_activity` 접속 0 행 생성 확인.

## §8 추가 수신분 처분 (유호 6~15신 · 08-06 「필요한 건 다 넣어줘」)

판정 축은 하나 — **「지금 안 넣으면 나중에 못 만드는가」**. 나중에 만들 수 있는 것은 지금 넣지 않는다(원본 WAV·원문이 보존되므로 파생은 언제든 재계산된다).

### 기각·보류 (판정 유지 · 재론 불요)

- 🚫 **노이즈 다양화·하드모드 소음** — 소음은 사후 합성 가능. 수집 항목이 아니라 경험 백로그(2신 ⑨ 판정 유지).
- 🚫 **조음 위치 3D 시각화(혀·입술)** — 단안 카메라엔 기준자가 없어 절대값이 안 나온다. 원순 모음 3쌍·서버측으로 축소된 것이 정본(§7).
- ⏸ **음소 단위 Forced Alignment** — 지금 안 한다. **원본 WAV를 무손실로 보존하므로 언제든 소급 가능**하고, 지금 붙이면 파이프라인만 무거워진다.
- ⏸ 세션 리포트·TTS 3단계 속도·상대 랭킹·신조어 DB·비자 RAG 지식베이스·B2B 산업 데이터셋 — **전부 수집이 아니라 앱 기능/콘텐츠**다. 필요한 원천(어휘 등급·WPM·정적·오류 유형)은 이미 위 스키마에서 파생된다.
- ⏳ **상급생이 몽골어로 해설**(H-1) — 2신 도전안 「선배 학생 유료 마이크로워크」와 같은 항목, 유호 답 대기 중.
- ⏳ **문화적 거부감·정의적 여과막**(H-4) — 검수자가 판정할 수 없는 값(학생 자기보고여야 함). 앱 2단계에서 1문항으로.
