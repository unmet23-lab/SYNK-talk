# 자동 밟기 (Maestro) — 기기 위에서 실제로 눌러 보는 층

## 왜 있나

이 저장소의 회귀 145벌은 **기기를 안 켠다.** `tests/lib/화면세우기.js` 머리말이 그 한계를
스스로 못박았다 — *「expo-* 를 끌고 오는 화면(말하기·답장·도착확인)은 아직 못 연다 … 그건
실기기 몫이다」*, *「이 통로는 첫 렌더만 본다」*.

그런데 우리 앱의 급소가 정확히 거기다: **녹음**(`expo-audio` + 마이크 권한). 모킹으로 재면
「내가 만든 가짜」를 재게 된다. 눌러 보는 것 말고 방법이 없다.

## 실유저가 0명인데 왜 지금 짓나

유호님이 한국에 계셔서 몽골 실유저 모집이 까다롭다. 그래서 **합성 밟기가 당분간 유일한
관측원**이고, Sentry 와 한 벌로 돈다 — 밟는 것이 없으면 Sentry 에 들어올 이벤트도 0이다.

## 손잡이(testID) 규약

흐름은 **카피가 아니라 손잡이로** 잡는다. 카피 감사가 52곳을 한 번에 바꾼 이력이 있어서,
텍스트로 잡으면 확정적으로 깨진다.

| 접두 | 어디서 오나 | 예 |
|---|---|---|
| `입력-` | `인증화면.칸` 의 `id` prop | `입력-학생번호` |
| `곁길-` | `인증화면.곁길` 의 `id` prop | `곁길-첫등록` |
| `답장-` | **계약 값목록** `교정API.학생응답값` | `답장-채택` |
| 그 밖 | 화면에 직접 박은 리터럴 | `녹음-시작` · `말하기-보내기` |

`답장-` 만 계약에서 오는 이유: 그 값(`채택`·`무시`·`수정`)은 서버와의 계약이라 카피처럼
안 흔들린다. 카피(`답문구[값]`)와 갈라 둔 자리가 그대로 손잡이가 된다.

**손잡이가 사라지면 `tests/자동밟기손잡이.test.js` 가 잡는다** — Maestro CLI 없이, CI 없이.
그게 이 폴더에서 유일하게 자동으로 도는 검사다.

## 돌리는 법

```bash
node tools/앱밟기.js
```

먼저 세울 것:
1. Maestro CLI (Windows 는 WSL 이 필요할 수 있다)
2. 안드로이드 에뮬레이터 또는 USB 기기
3. `MAESTRO_학생번호` · `MAESTRO_비밀번호` — **리허설 DB 의 합성 계정만**
4. `eas build --profile 합성밟기 --platform android` 로 구운 앱

> 🔴 **`합성밟기` 프로필이라야 한다.** 그 프로필만 `EXPO_PUBLIC_합성밟기=1` 을 번들에 박고,
> 그 값이 Sentry 이벤트의 `출처` 태그를 가른다. 다른 프로필로 구운 앱을 밟으면 합성 크래시가
> **실사용으로** 쌓이고 — 그건 나중에 소급으로 못 가른다.
> 기기에서 확인: 설정 → 배포 도착 확인 → 「관측(Sentry)」 = `켜짐 · 합성밟기`

## 🔴 아직 검증 안 된 것 (정직하게)

- **이 흐름들은 한 번도 안 돌았다.** 노트북에 Maestro CLI 가 없어서 YAML 문법도, 명령어
  유효성도 실측 못 했다. 첫 실행에서 고칠 자리가 나올 것으로 본다.
- `tests/자동밟기손잡이.test.js` 가 초록인 것은 **「부르는 이름이 화면에 있다」까지**다.
  그것을 「자동 밟기가 돈다」로 읽지 않는다.

## 아직 «안 지은» 흐름 (화면 경로를 직접 못 봐서 지어내지 않았다)

- **동의 없음 차단** — 동의 게이트가 어느 화면 어느 단계에 서는지 확인 후
- **오늘 과제 빈 상태** — 빈 상태 화면의 손잡이 확인 후
- **오프라인 → 재연결 → 제출** — Maestro 의 네트워크 제어 명령이 이 기기에서 실제로 먹는지
  확인 후 (`02_녹음제출.yaml` 은 지금 온라인 경로만 밟는다)
- **제출이 서버에 닿았는지** — `도착확인` 화면의 「못 보낸 것」 수를 읽는 단계

## 격리 규칙 (안 지키면 이해 대장이 오염된다)

- 리허설 DB 만. 운영 계정·운영 프로젝트는 밟지 않는다.
- 합성이 만든 데이터는 **골든셋에 자동 편입하지 않는다**(기존 🚫 그대로).
- 합성 밟기로 잴 수 있는 것은 **배선이 섰나**까지다. 「엔진이 학생 성향을 파악하나」는
  못 잰다 — 합성 학생의 성향은 내가 넣은 값이라 그걸 되읽으면 동어반복이다.
