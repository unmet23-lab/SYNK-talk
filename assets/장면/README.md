# 편지 작업실

G1의 방법 선택·답장 대기 장면. 유호의 「색과 캐릭터가 살아 있는 스튜디오」 선택에 따라 현행 몽글·까몽·마린 본체를 참조해 Codex imagegen으로 생성했다. 세 친구가 함께 있는 환경 그림이며 개별 가이드 선택값을 대신하지 않는다.

첫 장면에 대해 유호는 「사진 너무 훌륭하게 이쁘게 잘 나왔는데 마린이 팔이 4개다」라고 피드백했다. 같은 장면을 imagegen으로 편집해 마린의 여분 팔을 제거했다. 최종본은 엽서를 잡는 팔 둘과 책상에 딛는 다리 둘이다. 장면에 대한 긍정 피드백을 UI 전체 승인으로 확대하지 않는다.

실제 생성 원본과 앱 WebP는 **1672×941**이다. 확대하지 않았고 4K 원본으로 표기하지 않는다. 앱 파일은 209,242B이며 표시할 때 화면에 맞게 줄인다. 로고와 개별 캐릭터 원본은 `../브랜드/출처.json`에 따로 있다.

생성·수정 프롬프트, 원본 경로, 참조 파일과 SHA-256은 `편지작업실_출처.json`에 있다. PNG 원본은 imagegen 기본 저장 위치에 남겼다. 선택한 원본에서 동일한 앱 파일을 다시 만드는 명령:

```text
node tools/작업실자산반입.js
node tools/작업실자산반입.js --원본 <동일한 SHA-256의 PNG 경로>
```

원본·산출 지문을 모두 확인하므로 다른 그림을 같은 파일명으로 바꿔 끼우지 않는다. 프롬프트 재호출만으로 같은 픽셀이 재생성된다고 보장하지 않는다.
