# BGM — 미니게임 측정 스테이지 (생성물 폴더)

> **WAV 는 git 에 없다**(1MB 가드 · 생성물) — **정본은 `tools/BGM빌드.js`**(결정적 렌더 · 같은 코드 = 같은 바이트).
> `npm install`(postinstall)이 재생성하고, `node tools/BGM빌드.js --check` 가 손 편집을 잡는다.

- ✅ **선정 완료(유호 08-11 「너무 마음에 들어. 23번으로 커밋할게」)** — 정식 트랙 = `synk-bgm-measure.wav`
  (깔림 — 패드+저음 맥동 · 26.7s 루프 · `측정템포BPM=72` 고정 · C 펜타토닉 · 피크 −6dBFS).
- 확정 이력: 후보 a(물결)·b(별빛) 시청 → 유호 「깔리는 소리 너무 좋아 · 게임소리같이 튀는 소리는 빼자」
  → 종·아르페지오 층 전면 제거(깔림판 c) → c 선정·승격. **🚫튀는 층(멜로디·종) 복원** — 멜로디는 효과음 3종의 몫.
- 재생은 `src/소리.js` 만 — 인자 없이 `bgm재생()`(기본 = 이 트랙) · 전역 게이트가 녹음 중 음소거를 진다.
  09-11 최신 요청에 따라 BGM이 필요한 자리에는 담당 AI가 보유 곡에서 목적에 맞게 선곡한다. 곡마다 새 승인을 요구하던 과거 조건은 이 범위에 적용하지 않는다.

현재 선곡 기준은 형제 appsscript의 `docs/음악자산_장부.md` 「BGM 선곡 기준」이다. 유호가 추가하는 Suno 곡도 후보에 포함한다. G1의 구형 BGM은 제거된 상태이며 현재 읽기·쓰기 화면은 무음으로 둔다. 다른 게임의 기존 기본 트랙과 녹음 음소거는 유지한다.
