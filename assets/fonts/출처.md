## Inter Tight — ✅ 2026-08-27 탑재

정본 §5 규칙이 요구한 「`ө`·`ү`를 직접 찍어보고 넣는다」를 **글리프 표를 직접 세어** 지켰다:
네 굵기 전부 **몽골 키릴 70/70**(러시아어 33자 + 몽골 고유 `Өө`·`Үү` · `fontTools` cmap 실측).
즉 이 파일들은 라틴 전용 subset이 **아니다** — 이름만 보고 「키릴판이겠지」로 판정하지 않았다.

- 실은 것 **셋**: Regular(400) · Medium(500) · SemiBold(600).
  🚫 Bold(700)·800은 안 싣는다 — 몽골어가 헤드로 가는 자리가 지금 없고, 안 쓰는 폰트는 번들만 무겁게 한다.
  ⚠ Inter Tight에는 **800이 아예 없다**. 헤드 자리에 몽골어를 넣어야 하면 굵기 선택부터 다시 정한다.
- 무엇을 어디에 쓰는지의 정본 = `src/테마.js`의 `몽골어` 상수 + `몽골어폰트` 표 하나.
- 회귀 = `tests/몽골어폰트.test.js` — ①등록·파일 존재 ②**cmap을 직접 읽어** 키릴 존재 확인
  ③「병기」 줄이 SUIT을 안 쓰는지. ③이 실제로 두 화면을 잡았다(`막힘카드`·`생성카드` · 08-27).
- ⚠ **눈 판정은 아직 유호님 몫**이다 — 글리프가 「있다」와 「우리 락업 옆에서 좋다」는 다른 축이다
  (`docs/브랜드_폰트_정본.md` §5 · memory `color-adoption-needs-eye-axis`).
