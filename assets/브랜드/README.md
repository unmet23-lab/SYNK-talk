# 화면용 현행 브랜드 자산

`node tools/브랜드자산반입.js --정본 C:/Users/q1212/Documents/SYNK-appsscript`로 만든 앱 파생이다. 원본 경로·SHA-256·실제 치수·변환은 [출처.json](출처.json)에 기록한다.

- 내부 로고: 현재 `tools/lib/로고정본.js`의 다크·꺾쇠·펠트 `syn<`. 도형·색·실땀을 새로 정하지 않는다. `내부로고_4K.png`는 원래 프레임을 보존한 4096×2703 로컬 렌더이며 Git에 넣지 않는다. 브랜치 복제 후 위 생성기를 실행하면 생긴다. 저장소에는 SVG·앱 WebP·생성기·지문을 남긴다. 전송용 WebP만 알파가 있는 전체 경계와 폭의 1% 여백으로 자른 뒤 비례 축소한다.
- 몽글·까몽·마린: `tools/lib/마스코트자산.js`가 고른 승인 4096×4096 투명 본체에서 1024×1024 WebP로 변환했다. 원본 프레임·몸·표정·의상·알파를 유지한다.

화면은 `src/브랜드자산.js`의 `내부로고`와 `가이드그림[캐릭터]`를 쓴다. 가이드 선택값이 없으면 이 모듈은 캐릭터를 대신 고르지 않는다. 전송용 그림은 표시 너비 512px까지 원본 대비 최소 2배 픽셀을 제공하며, 더 큰 자리는 원본에서 새 크기로 변환한다.
