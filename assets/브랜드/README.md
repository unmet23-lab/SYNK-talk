# 화면용 현행 브랜드 자산

`node tools/브랜드자산반입.js --정본 C:/Users/q1212/Documents/SYNK-appsscript`로 만든 앱 파생이다. 원본 경로·SHA-256·실제 치수·변환은 [출처.json](출처.json)에 기록한다.

- LAB 로고: 현재 사진형 펠트 킷 `배치용/SYNK-LAB-Paper.png`의 완성 조합을 쓴다. SYNK 네 글자는 무실땀, LAB는 기존 코랄·실땀 그대로다. 배치명세의 SHA·치수를 확인하고 원본 프레임·알파·간격·형태를 보존해 1024px 폭 WebP로 비례 축소한다. 원본과 사업명을 다시 조립하거나 확대하지 않는다.
- 로고 해상도: 승인 배치 원본은 3468×1082다. 킷에 기록된 표면 편집 원천은 1804×872·1788×880이므로 큰 배치 캔버스를 처음부터 4K로 생성한 표면 디테일로 설명하지 않는다. 원본 PNG는 appsscript 정본에 보존하고 이 저장소에는 앱 파생·출처·생성기를 둔다.
- 몽글·까몽·마린: `tools/lib/마스코트자산.js`가 고른 승인 4096×4096 투명 본체에서 1024×1024 WebP로 변환했다. 원본 프레임·몸·표정·의상·알파를 유지한다.

화면은 `src/브랜드자산.js`의 `LAB로고`와 `가이드그림[캐릭터]`를 쓴다. 가이드 선택값이 없으면 이 모듈은 캐릭터를 대신 고르지 않는다. 전송용 그림은 표시 너비 512px까지 최소 2배 픽셀을 제공하며, 더 큰 자리는 원본에서 새 크기로 변환한다. LAB 로고는 Ink Deep 배경에 150×47px 정도로 먼저 확인하고, 작아 읽히지 않으면 사업명만 재칠하지 않고 조합 전체의 표시 크기를 조정한다.
