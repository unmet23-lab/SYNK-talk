## 컷 6종만 싣는 이유

표정 어휘(`lib/마스코트생명.표정컷`)에 소비자가 있는 컷만 싣는다 — 슬픔 4컷은 어느 반응
지도 줄도 안 쓰고(실패에 부정 반응 금지), 비니 4컷은 모자 «부위 수확용»이라 부유 본체가
아니다(정본 README 조립 규칙). 새 컷을 쓰는 날: 변환(아래) → `표정컷`에 한 줄 →
`src/마스코트.js` 컷 지도에 require 한 줄 (회귀 `tests/마스코트자산.test.js`·`마스코트배선.test.js`가 아귀를 잡는다).

| 파일 | 역할 |
|---|---|
| 본체.webp | 기본(점눈) — 모든 화면의 기본값 |
| 본채깜찍.webp | 기쁨 — 보상 순간 전용(상시 금지 · 「본채」는 유호 원본 표기) |
| 본체별눈.webp | **별눈 — 최상급. 자산만 준비돼 있고 배선이 없다**: 허용 다섯 사건(진화·생애 첫 셋·시즌 완주)의 신호가 앱에 아직 0이라, `lib/마스코트생명.별눈판정` 게이트를 지나는 배선이 서는 날 열린다 |
| 본체놀람.webp | 놀람(은은) — 탭·무오류 첫 열람의 첫 박자 |
| 본체눈감음.webp | 눈웃음(∪∪) — 탭 반응 한 갈래 |
| 본체눈감음2.webp | 잔잔 감음(⌒⌒) — 깜빡임 프레임·졸림 |

## 변환 규격 (tools/마스코트변환.py)

- **누끼**: 원본은 불투명 스튜디오 회색 배경(실측 `#E6E4E2`대·A=255). 저채도(sat<30)·밝음(lum>140)
  후보를 가장자리에서 플러드필해 배경만 걷는다 — 유리 몸 안 흰 하이라이트는 안 이어져 살고,
  바닥 그림자는 배경과 이어져 함께 걷힌다(앱은 부유라 그림자 불필요).
- **512² WebP q95** (LANCZOS · 페더 2px + 초크 1.6 — 회색 헤일로 방지). SVG 변환은 정본이 금지.
