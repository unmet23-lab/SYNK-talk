| 파일 | 역할 |

| 몽글_본체.webp | 기본 — 모든 화면의 기본값 |

| 몽글_눈웃음.webp | 눈웃음(자수 ^^) — 탭 반응 한 갈래 · **기쁨(보상)도 임시로 이 컷**(펠트 깜찍판 미존재) |

- **깜찍(기쁨 전용판)**: 지금은 눈웃음이 보상 순간을 댄다(표현 예산 「웃음은 눈의 곡선으로」와 정합).
- **별눈**: 발동 신호(진화·생애 첫 셋·시즌 완주)도 앱에 아직 0 — 게이트(`별눈판정`)만 산다.

## 변환 규격 (tools/마스코트변환.py)

- 정본이 이미 투명 4096² PNG 라 **리사이즈 + WebP + 실측**만 한다(옛 판의 플러드필 누끼
  로직은 정본 교체와 함께 지웠다). 캐릭터 하나만 다시 변환할 땐 `python tools/마스코트변환.py 까몽`.
- **336² WebP q92** (LANCZOS · 표시 84pt × @4x) · 실측 = 모서리 α 0 · 중심 α >200 · 눈검수
  시트는 캐릭터별(몽글 = `마스코트_시트.png` · 까몽 = `마스코트_시트_까몽.png`) — 앱 바탕색
  (#080605) 위 대조판이다(라이트 지면에선 알파 구멍이 안 보인다).
- 변환 실측(09-05 · 4K 정본): 몽글 4컷 **29~31KB** · 까몽 8컷 **18~20KB** — 전부 모서리 α=0 ·
  중심 α=255. ⚠ 옛 판(1024 정본)에서는 몽글 18KB · 까몽 26~27KB 였다. 무게가 뒤집힌 것은
  규격이 아니라 **그림이 바뀌었기** 때문이다(몽글이 결이 촘촘해지고 까몽이 단순해졌다).
