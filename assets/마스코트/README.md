## 변환 규격 (tools/마스코트변환.py)

- 정본 누끼가 이미 투명 1024² PNG 라 **리사이즈 + WebP + 실측**만 한다(옛 판의 플러드필 누끼
  로직은 정본 교체와 함께 지웠다). 캐릭터 하나만 다시 변환할 땐 `python tools/마스코트변환.py 까몽`.
- **336² WebP q92** (LANCZOS · 표시 84pt × @4x) · 실측 = 모서리 α 0 · 중심 α >200 · 눈검수
  시트는 캐릭터별(몽글 = `마스코트_시트.png` · 까몽 = `마스코트_시트_까몽.png`) — 앱 바탕색
  (#080605) 위 대조판이다(라이트 지면에선 알파 구멍이 안 보인다).
- 변환 실측(몽글 08-23): 4컷 모두 모서리 α=0 · 중심 α=255 · 각 18KB.
- 변환 실측(까몽 08-31): 8컷 모두 모서리 α=0 · 중심 α=255 · 각 26~27KB.
